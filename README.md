## Basic vs Final: what changed

The HTML content is the same in both. Every difference below comes from CSS.

| Part | Basic | Final |
|---|---|---|
| Colors | White page, black text, blue links | Dark background with gold accents |
| Layout | One stacked column | Navbar, hero section, aligned blocks |
| Buttons and links | Plain underlined links | Gold gradient buttons with hover effects |
| Photo | Original size | Sized, framed and positioned |

## Myntra style store

- Sticky navbar with a different hover color for each menu, like the real app
- Ticket style offer strip, festival banner and brand strip
- 16 product cards with hover zoom and a wishlist button that slides up
- Clicking a card opens a product page with price, MRP, discount, size selection, **Add to Bag** and **Wishlist**
- Responsive: works on desktop, tablet and mobile widths

## Run it on your computer

1. Download or clone this repository
2. Open any project folder
3. Double click `index.html`, or use the **Live Server** extension in VS Code

No installation is needed.
